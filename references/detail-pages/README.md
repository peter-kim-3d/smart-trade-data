# references/detail-pages/ — 상세페이지 레퍼런스 (리버스엔지니어링 원료 + 품질 기준)

가공·생성 스킬(`process-product`, `generate-page`)이 **무엇을 만들어야 하는지 학습하는 원료**이자, 이후 산출물 **품질 비교의 기준**이 되는 실제 상세페이지 사례 모음.

## 규약

- 사례당 폴더: `references/detail-pages/{사례명}/`
- 각 폴더에 **실제 출력물**(`.jpg` / `.html`) + **`분석.md`** 를 둔다.
- 무거운 원본(`.psd`, 원본 동영상 등)은 넣지 않는다 — 최종 출력물과 분석만.
- `분석.md` 는 아래 골격을 따른다(내용은 사례를 보고 채운다).

## 분석.md 골격

```markdown
# {사례명} 분석

## 페이지 구조
(섹션 순서·길이·구성)

## 카피 톤
(문체·후킹·CTA·언어)

## 이미지 배치
(메인/상세/비교/디테일컷 배치·개수·크기)

## 가격·스펙 표기
(가격/옵션/SKU/배송 노출 방식)

## 이 사례에서 배울 것
(우리 생성물에 적용할 포인트)
```

## 현재 사례

*(아직 없음 — 실제 상세페이지 결과물을 임포트하면 사례 폴더가 생긴다.)*
