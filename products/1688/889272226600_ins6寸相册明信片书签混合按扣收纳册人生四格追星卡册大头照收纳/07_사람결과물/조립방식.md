# 889272226600 버전 A 상세페이지 조립 방식

> 대상: `생성기획서.md` 버전 A의 11개 블록
> 사실성 기준: `데이터검증.md`의 **확실** 값만 사용한다. `검증 필요`·`상충` 값은 판매 카피와 이미지에서 제외한다.

## 결론

**11개 블록을 각각 독립된 세로형 이미지로 제작하고, 같은 순서로 업로드하는 방식을 기본 산출물로 채택한다.**

- 공통 마스터: **가로 860px, RGB JPEG**(투명 배경·선화가 꼭 필요한 경우만 PNG)
- 쿠팡용 파생본: 공통 마스터에서 **가로 780px**로 일괄 축소
- 네이버용: **가로 860px** 마스터 사용
- 선택 산출물: 검수·공유용으로만 11개 블록을 이어 붙인 긴 미리보기 1장 생성
- HTML: 최종 업로드물이 아니라 내부 순서·간격 확인용 프리뷰에만 사용

최종 등록 전에 해당 시점의 판매자센터 업로드 제한(파일당 용량, 총 높이·개수, 지원 형식)을 다시 확인하고 실제 등록 화면에서 1회 업로드 검증한다. 정책이 바뀌더라도 860px 마스터에서 채널별 파생본을 다시 만들 수 있다.

## 왜 개별 블록 이미지가 최선인가

### 1. 하나의 긴 세로 이미지보다 안전하다

- 한 블록만 수정해도 전체 페이지를 다시 내보낼 필요가 없다.
- KC·배송·교환처럼 운영 중 바뀌는 정보만 교체할 수 있다.
- 지나치게 긴 이미지에서 생기는 파일 용량, 로딩, 편집기 높이 제한 위험을 줄인다.
- 블록 순서를 채널별로 바꾸거나 일부 블록을 보류하기 쉽다.
- 모바일에서 문제가 생긴 블록을 빠르게 찾아 재업로드할 수 있다.

긴 이미지는 전체 흐름 확인에는 편하지만 **편집 원본이나 유일한 업로드 파일로 쓰지 않는다.**

### 2. HTML을 최종본으로 쓰지 않는 이유

우리 환경에서 HTML/CSS 템플릿 자체는 만들 수 있지만, 마켓 상세설명 편집기는 임의 HTML/CSS를 제한하거나 정리할 수 있고 외부 이미지 호스팅에도 의존한다. 쿠팡·네이버 양쪽에 같은 모양을 안정적으로 재현하기 어렵다.

따라서 HTML은 다음 용도로만 제한한다.

- 11개 이미지의 순서·여백을 검수하는 내부 프리뷰
- 향후 이미지 일괄 렌더링 템플릿

**실제 판매 채널에는 RGB JPEG/PNG 블록을 직접 업로드한다.**

## 이미지 블록과 텍스트 배너의 통합 방식

두 종류 모두 최종적으로는 같은 폭의 이미지 블록으로 통일한다.

### (가) 제품 이미지 블록

1. `06_가공/final_A`, `final_B`의 제품 이미지를 사용한다.
2. 사진·제품 형태는 유지한다.
3. 새 헤드라인, 검증값, 아이콘·카드는 별도 레이어로 합성한다.
4. 정확한 한글과 숫자가 중요한 치수·상품정보는 생성 모델에 다시 쓰게 하지 않고 결정론적 텍스트 합성을 우선한다.

### (나) 텍스트 배너 블록

제품 사진 없이 같은 860px 그리드로 제작한다.

- KC/안전: 확인 전에는 KC 마크, 인증번호, `인증 완료`, `비대상`을 넣지 않는다.
- 배송·교환: 실제 판매자 정책이 확정된 뒤 구체값을 넣는다.
- 리뷰 유도: 가짜 별점·후기·혜택을 넣지 않는다.
- 배경색, 제목 크기, 좌우 여백을 이미지 블록과 동일하게 맞춘다.

이렇게 하면 사진 블록과 배너 블록이 섞여도 사용자는 한 상세페이지로 인식하고, 운영자는 정책 배너만 따로 교체할 수 있다.

## 권장 제작 규격

| 항목 | 기준 |
|---|---|
| 마스터 폭 | 860px |
| 블록 높이 | 내용에 따라 약 520~1,300px, 불필요하게 길게 만들지 않음 |
| 색상 | sRGB/RGB |
| 기본 형식 | JPEG, 품질 90~92 |
| 예외 형식 | 투명 배경·선화가 필요할 때만 PNG |
| 안전 여백 | 좌우 최소 40px, 핵심 카피는 가장자리에서 충분히 이격 |
| 본문 글자 | 860px 기준 최소 약 22px, 핵심 제목은 약 40px 이상 |
| 파일명 | `블록01_후킹.jpg`처럼 순번 고정 |

## 사실성 적용 규칙

`데이터검증.md`를 최우선으로 따른다.

### 사용 가능

- 외피 높이 17.5cm
- 외피 두께 2.5cm
- 2칸 포켓 5×16cm
- 1칸 포켓 10.3×16cm
- 양면 수납
- 스냅 단추가 위로 열리는 구조
- 투명 속지, 투명 무광 외피, DIY 표지
- 책갈피·엽서 혼합 수납

### 확인 전 사용 금지

- 외피 폭 12.9cm와 12.5cm 모두
- 내지 외곽 11×16.5cm
- 각 20매, 80매, 40매
- 네컷사진·4×6 사진 호환을 확정하는 표현
- 제품명 `네컷사진 보관 앨범`을 규격 사실처럼 쓰는 표현
- 재질 PP, 원산지 중국, 제조사
- 확인되지 않은 KC·배송·교환·리뷰 혜택 정보

## 전체 제작 시 권장 공정

1. 11개 블록별 카피를 먼저 잠그고 `데이터검증.md`와 대조한다.
2. 제품 사진 편집이 필요한 부분만 gpt-image를 사용한다.
3. 한글 카피·수치·정책 문구는 결정론적 레이어로 합성한다.
4. 860px 마스터를 블록별로 저장한다.
5. 모든 블록을 이어 붙인 내부 미리보기로 흐름을 검수한다.
6. 독립 검수에서 오탈자, 금지값, 제품 왜곡, 모바일 가독성을 확인한다.
7. 쿠팡용 780px 파생본을 일괄 생성한다.
8. 각 판매자센터에서 실제 업로드 테스트 후 게시한다.
