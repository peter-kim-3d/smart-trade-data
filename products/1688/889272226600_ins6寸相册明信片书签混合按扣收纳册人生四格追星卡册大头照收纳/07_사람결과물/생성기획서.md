## A. 페이지 블록 구성 (순서대로)

### 1. 후킹 배너 — “여러 포맷을 한 권에”

- **목적:** 첫 화면에서 단순 책갈피 앨범이 아니라 사진·엽서·책갈피를 함께 정리하는 멀티 수납 앨범임을 즉시 전달한다.
- **사용할 이미지:** `06_가공/final_B/메인_01.jpg` 우선. 동일 장면의 정보형 대안은 `06_가공/final_A/메인_01.jpg`.
- **넣을 카피/텍스트:**
  - 헤드라인: `소중한 조각을 한 권에`
  - 서브: `네컷사진부터 4×6 사진·엽서·책갈피까지`
  - 상품명: `멀티 포토 수납 앨범`
- **사람 결과물의 대응 블록과 비교:** 사람은 토끼 책갈피 2장과 고양이 4×6 사진이 꽂힌 파스텔 연출컷 위에 `네컷사진 보관 앨범`을 크게 배치했다. 우리 이미지는 제품과 혼합 수납 형식은 보이지만 유화풍 삽입물과 작업실 배경이라 한국형 네컷사진 맥락과 감성 통일감은 약하다.

### 2. 감성·타깃 공감 — “흩어진 사진을 모으는 사람”

- **목적:** 네컷사진, 인화 사진, 엽서, 책갈피를 따로 보관해 온 사용자의 정리 고민에 공감시킨다.
- **사용할 이미지:** `06_가공/final_B/동영상_커버.jpg`.
- **넣을 카피/텍스트:**
  - 헤드라인: `좋아하는 순간, 여기저기 흩어두지 마세요`
  - 본문: `크기가 다른 기록도 한 권에 차곡차곡`
  - 타깃 라벨: `네컷사진 · 4×6 사진 · 엽서 · 책갈피`
- **사람 결과물의 대응 블록과 비교:** 사람은 후킹 직후 `네컷 사진 마니아들 주목!`과 `네컷 사진부터 기본 인화 사이즈인 4x6사이즈까지`라는 직접 호명형 문구를 넣었다. 우리 동영상 커버는 사람이 속지를 들고 있는 장면이라 사용 공감에는 적합하지만, 현재 이미지 안의 `일상을 채우는 아이템 더 보기`는 상세페이지 문맥과 맞지 않아 실제 제작 시 해당 보조 문구를 그대로 쓰지 않는 편이 낫다.

### 3. 치수·규격 — 구매 전 크기 확인

- **목적:** 앨범 외형과 두 포켓 규격, 여닫는 방식을 한 번에 확인하게 한다.
- **사용할 이미지:** `06_가공/final_A/메인_06.jpg`.
- **넣을 카피/텍스트:** 이미지에 이미 들어간 확인값을 유지한다.
  - `외피 17.5×12.9×2.5cm`
  - `2칸 5×16cm · 1칸 10.3×16cm`
  - `양면 수납 · 상단 스냅 오픈`
  - 보조 제목: `구매 전 사이즈를 확인하세요`
- **사람 결과물의 대응 블록과 비교:** 사람은 닫힌 제품에 높이 17.5cm·너비 12.5cm·두께 2.5cm를 화살표로 표시한 뒤 내지 외곽과 포켓 치수를 별도 도식으로 제시했다. 우리 이미지는 한 장에 정보가 모여 효율적이지만 외형 치수의 화살표 도식이 없고, 사람 결과물의 12.5cm와 우리 근거값 12.9cm가 충돌하므로 12.9cm를 기준으로 하되 실물 검수 전 최종 확정이 필요하다.

### 4. 옵션·수납 구조 — 두 가지 포켓과 양면 수납

- **목적:** 색상 옵션이 아니라 이 상품의 핵심 선택 구조인 `1칸/2칸 포켓`과 양면 수납을 설명한다.
- **사용할 이미지:** `06_가공/final_A/메인_03.jpg` + `06_가공/final_B/메인_06.jpg`를 연속 배치.
- **넣을 카피/텍스트:**

- **목적:** 반투명 외피와 투명 속지를 통해 수납물을 펼쳐 감상하는 경험을 강조한다.

- **목적:** 배송 일정, 반품 가능 조건, 교환 제한 사유를 결제 전에 명확히 안내한다.

- **넣을 카피/텍스트:**

`상세_01~05.jpg`는 각각 `메인_01~05.jpg`와 같은 장면의 중복 자산이므로 페이지 길이를 늘리기 위해 반복 사용하지 않는다. `final_A`는 규격·기능 블록, `final_B`는 후킹·감성 블록 중심으로 혼합하는 것이 좋다.

### 2. 부족해서 신규 생성이 필요한 블록과 대안

| 부족분 | 왜 부족한가 | 1순위 대안 | 2순위 대안 | 생략 여부 |
|---|---|---|---|---|
| 한국형 파스텔 후킹컷 | 현재 후킹 이미지는 작업실 배경·유화풍 삽입물이며 네컷사진 맥락이 약함 | 실제 제품을 기준으로 파스텔 연출컷 신규 생성 시도 | `final_B/메인_01.jpg` 사용 + 텍스트에서 네컷사진 타깃 보완 | 버전 A에서는 생략 가능, 버전 B에서는 생성 우선 |

## C. 전환요소 블록 (우리 차별점)

### 1. KC 인증/안전 표시

- **위치:** 치수·규격 다음에 간단 신뢰 배지로 1회, 하단 상품정보에 상세 항목으로 1회.
- **구현:** 이미지 생성 없이 흰색/연회색 카드형 텍스트 배너와 체크 아이콘으로 가능.
- **필수 조건:** 인증 대상 여부를 먼저 확인한다. 대상이면 인증서와 번호를 대조하고, 비대상이면 관련 법적 분류를 확인한다. 확인 전에는 KC 마크나 `인증 완료`를 쓰지 않는다.
- **권장 문구:** 확인 전 기획용 `안전·표시 정보를 확인하세요`; 확인 후 실제 인증/비대상 정보를 구체값으로 교체.

### 2. 배송·교환

- **위치:** 모든 사용·꾸미기 설명이 끝난 뒤, 리뷰 유도와 상품정보 앞.
- **구현:** 트럭·교환 화살표·박스 아이콘과 텍스트만으로 가능. 제품 이미지는 불필요하다.
- **내용:** 출고 예정일, 배송비, 도서산간 추가비, 단순 변심 반품 기한·비용, 오배송/불량 교환, 사용·훼손 시 제한.
- **주의:** `무료배송`, `당일발송`, 교환비 등은 운영 정책 확인 없이 예시값을 넣지 않는다.

### 3. 리뷰 유도

- **위치:** 배송·교환 뒤, 최종 상품정보 직전.
- **구현:** 파스텔 배경의 짧은 텍스트 배너만으로 가능. 초기에는 허위 리뷰 이미지나 가상의 별점을 쓰지 않는다.
- **권장 문구:** `나만의 한 권을 보여주세요` / `어떤 사진과 기록을 담았는지 포토리뷰로 공유해 주세요.`
- **운영 연동:** 적립금·쿠폰을 실제 제공할 때만 혜택 문구를 추가한다.

## D. 두 버전 계획

### 버전 A — 우리 `06_가공` 이미지 재배치+카피

**목표:** 추가 이미지 생성 없이 현재 자산만으로 정보 구조와 전환 요소를 개선한다.

**블록 구성:**

1. 후킹 — `final_B/메인_01.jpg` + `소중한 조각을 한 권에`
2. 감성·타깃 공감 — `final_B/동영상_커버.jpg` + 네컷사진/4×6/엽서/책갈피 타깃 문구
3. 치수·규격 — `final_A/메인_06.jpg`
4. 1칸·2칸/양면 구조 — `final_A/메인_03.jpg` + `final_B/메인_06.jpg`
5. 사용 장면 — `final_B/메인_03.jpg`
6. 투명 속지 — `final_B/메인_04.jpg`
7. 꾸미기 — `final_B/메인_02.jpg`
8. KC/안전 표시 — 텍스트 배너
9. 배송·교환 — 텍스트 배너
10. 리뷰 유도 — 텍스트 배너
11. 상품정보 — `final_A/메인_05.jpg` + 확인된 정보표

**장점:** 생성 리스크와 추가 촬영비가 없고, 규격·기능 정보는 현재 근거와 바로 연결된다.

**한계:** 작업실 배경, 유화풍 삽입물, 사람 사용컷의 다른 분위기가 섞여 사람 결과물처럼 하나의 파스텔 브랜드 촬영 세트로 보이기 어렵다. 네컷사진 타깃과 실제 한국형 사용 장면도 카피에 더 의존한다.

### 버전 B — gpt-image로 새 연출컷 생성 시도

**목표:** 사람 결과물의 통일된 파스텔 감성과 한국형 사용 맥락을 넘어서되, 제품 사실은 `06_가공`과 실물 자료로 고정한다.

**새로 만들 시도할 블록:**

1. **파스텔 후킹컷:** 반투명 스냅 앨범을 펼쳐 왼쪽 2칸에 네컷사진 2장, 오른쪽 1칸에 4×6 사진 1장을 넣고 꽃·엽서·리본을 배치한 상단 키비주얼.
2. **타깃 공감컷:** 책상 위에 흩어진 네컷사진·엽서·책갈피가 앨범 한 권으로 정리되는 전/후 개념 장면. 전/후를 한 이미지에서 과도하게 합성하기보다 2장의 짝 구성으로 시도.
3. **수납 구조컷:** 1칸·2칸 포켓과 상단 스냅이 정확히 보이는 정면 오픈 컷. 치수·매수 글자는 이미지 모델에 맡기지 않고 후편집 텍스트 레이어로 적용.
4. **꾸미기컷:** 첫 장에 사진·일러스트를 넣어 표지가 달라 보이는 2~3가지 스타일 제안. 실제 SKU 색상 옵션처럼 오해되지 않도록 동일 반투명 제품으로 유지.
5. **하단 제품 연출컷:** 제품 1~3권과 사진 소품을 밝은 크림 배경에 배치한 상품정보 전 브리지 이미지.

**리스크와 통제:**

- **제품 형태 왜곡:** 스냅 위치, 외피 비율, 제본부, 포켓 수가 바뀔 수 있다. `final_A/메인_05·06`을 형태 기준으로 삼고 결과마다 대조 검수한다.
- **포켓·치수 오류:** 1칸/2칸 구조나 17.5×12.9×2.5cm가 틀릴 수 있다. 생성 이미지 안에는 치수 문자를 넣지 않고 검증된 도식/텍스트를 별도 레이어로 적용한다.
- **가짜 옵션 생성:** 색상·구성품을 임의로 늘릴 수 있다. 확인된 단일 반투명 제품만 생성하고 SKU 확인 전 색상 옵션컷을 만들지 않는다.
- **투명 소재 표현 실패:** PP의 반투명도, 속지 광택, 겹침이 부자연스러울 수 있다. 실제 제품 기준 이미지와 나란히 검수하고 불일치 결과는 폐기한다.
- **수납량 과장:** 많은 사진을 넣은 장면이 실제 최대 수량처럼 오해될 수 있다. 검증 전 `80매/40매/각 20매` 문구는 넣지 않는다.
- **얼굴·저작권·가독성:** 네컷사진 속 인물은 비식별 또는 권리 확보 소재를 사용하고, 생성된 글자·로고는 제거한다.
- **가장 안전한 제작 방식:** 전체 제품을 새로 그리게 하기보다 실제 제품 컷을 유지하고 배경·소품 연출만 생성/합성하는 방식이 사실성에 유리하다.

**버전 B 권장 최소 범위:** 후킹컷, 네컷사진+4×6 사용컷, 하단 파스텔 연출컷의 3장만 먼저 시도한다. 규격·KC·배송·리뷰·상품정보는 버전 A와 같은 검증된 텍스트/도식 블록을 공통 사용한다.
