# process-images

## 언제 사용
process 채널에서 "가공"/"process" 요청 + offer id(또는 "미가공 목록" 요청)일 때.

## 접근 원칙 (중요)
이미지의 중국어는 EasyOCR 같은 로컬 OCR로 읽지 않는다 — 장식 폰트·저대비·세로 글씨를
놓친다(검증: EasyOCR 1/6 vs 직접 읽기 6/6). 반드시 네가 각 이미지를 직접 열어(뷰) 읽는다.

## 미가공 목록 요청 시
products/1688/INDEX.md 를 읽어 "가공" 열이 비어있는 상품 목록을 Slack에 보고. 처리는 안 함.

## 가공 절차 (offer id 하나당)
1. cd 리포루트 && git pull --rebase
2. 대상: products/1688/{id}_*/03_이미지/ 하위 모든 이미지 (메인+상세).
   폴더가 없으면 "수집 안 됨 — 먼저 수집 필요" 보고 후 중단.
3. 각 이미지를 직접 열어서 이미지에 그려진/합성된 중국어 마케팅 텍스트를 전부 읽는다.
   - 장식 폰트, 저대비 색 글씨, 세로 글씨도 놓치지 않는다.
   - 상품 사진에 우연히 찍힌 배경 소품의 글자(영문 등)는 제외. 마케팅 목적 텍스트만.
4. 읽은 중국어를 원문 의미 확인용 한국어 직역으로 옮겨 `ko`에 저장한다. 기존 `zh`/`ko` 번역 결과는 그대로 보존한다.
5. 각 텍스트 블록마다 한국어 카피 2종을 추가 생성한다.
   - `copy_a` (깔끔·미니멀): 짧고 담백한 한국 쇼핑몰 카피.
   - `copy_b` (감성·생활제안): 부드럽고 감성적인 생활 제안 톤의 카피.
   - 한 상품 안에서는 모든 `copy_a`끼리, 모든 `copy_b`끼리 각각 같은 톤을 유지한다.
6. products/1688/{id}_*/06_가공/text_extract.json 저장. 스키마:
   {
     "offer_id": "{id}",
     "method": "vlm",
     "generated_at": "YYYY-MM-DD",
     "images": [
       { "file": "<상품폴더 기준 상대경로>",
         "has_text": true/false,
         "texts": [
           {"zh":"..","ko":"..","copy_a":"..","copy_b":".."}
         ] }
     ]
   }
   `ko`는 번역 필드로 보존하고 `copy_a`/`copy_b`를 추가한다.
   텍스트 없는 이미지도 반드시 항목에 넣고 `has_text:false` + 빈 `texts` 배열을 유지한다.
7. INDEX.md 의 해당 상품 "가공" 열에 날짜 기록.
8. git add 해당 06_가공 + INDEX.md && commit "process(1688): {id} 텍스트추출" && push.
9. Slack 스레드 보고: 이미지 수 / 텍스트 있는 이미지 수 / 대표 예시 몇 개 [파일-중국어-한국어-copy_a-copy_b].

## 카피 원칙 (필수)
- `~습니다`/`~어요` 형식의 설명문 톤은 금지한다. 이미지에 바로 얹을 수 있는 짧은 카피로 쓴다.
- 자동번역·직역 느낌을 절대 남기지 않는다. 한국 쇼핑몰 MD가 작성한 문구처럼 자연스럽게 쓴다.
- 의역은 허용하되 제품 사실과 어긋나면 안 된다. 예: `书签`(북마크)을 임의로 다른 물건으로 바꾸지 않는다.
- 한 상품 안에서 A안끼리, B안끼리 어휘·문장 길이·분위기를 일관되게 유지한다.

## 06_가공/ 폴더 구조
```
06_가공/
├── text_extract.json  # 이 스킬이 생성: zh/ko + copy_a/copy_b
├── clean/             # 다음 이미지 정리 스킬이 생성
├── final_A/           # 다음 apply-copy 스킬이 copy_a를 적용해 생성
└── final_B/           # 다음 apply-copy 스킬이 copy_b를 적용해 생성
```
이 스킬은 `text_extract.json`만 만든다. `clean/`, `final_A/`, `final_B/`는 미리 만들지 않으며 다음 스킬들이 각각 생성한다.

## 지금 하지 않는 것 (범위 고정)
- 클린 이미지 생성(글자 지우기)·좌표 추출·카피가 적용된 이미지는 이 스킬 범위 밖이다.
- `clean/`, `final_A/`, `final_B/` 생성은 다음 단계의 별도 스킬이 담당한다.
- 가격·SKU 등은 이미 수집 데이터에 있으니 건드리지 않는다.
