# 생성 (page-generation) 플레이북

> **이 문서는 휴먼 피드백으로 계속 자라는 문서다.** 실전에서 배운 규칙을 절차·튜닝 로그에 계속 추가한다.

## 목적

가공 입력(`page_input.json`)과 `templates/` 를 사용해 상세페이지 초안(drafts)을 생성한다. (한 상품에서 여러 템플릿 변형을 만들 수 있다 — 세부는 `references/` 분석 후 확정.)

## 입력·출력 계약

- **입력**: `products/{site}/{id}_{슬러그}/06_가공/page_input.json` *(계약 정의 예정)* + `templates/{템플릿}/`
- **출력**: `products/{site}/{id}_{슬러그}/07_생성/` 아래 초안(drafts)
- `07_생성/` 폴더는 **첫 생성 실행 때 이 단계가 생성**한다(미리 만들지 않는다 — 폴더 존재 = 진행 상태 신호).
